# ☕ Coffee Date Invite

A fun, interactive web app to ask your friend out for coffee! This project features playful animations, a sneaky "NO" button that runs away, and a complete date/time scheduling system.

## 🎯 Features

✨ **Interactive UI** - Beautiful gradient backgrounds and smooth animations  
🎉 **Confetti Celebration** - Fireworks when they say YES  
🚫 **Sneaky NO Button** - The "NO" button runs away when you try to click it (they can't escape!)  
📅 **Date Picker** - Select month, date, and preferred time  
☕ **Coffee Ticket** - A cute confirmation ticket with all the details  
⏳ **Countdown Timer** - Displays how much time they have to schedule  
💬 **Hindi/Hinglish Messages** - Fun, friendly messages in mixed language  

## 📖 How to Use

1. **Open the page** - Just open `index.html` in your browser
2. **Share the link** - Send it to your friend
3. **They click YES** - Celebrate with confetti and hearts! 🎉
4. **They pick a date** - Month → Date → Time
5. **Screenshot time** - They take a screenshot and send it to you

## 🚀 How to Deploy

### Option 1: GitHub Pages (Easiest)
1. Go to your repository settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as the source
4. Your page will be live at: `https://RandomGuy2611.github.io/Coffee-date-/`

### Option 2: Netlify
1. Drag and drop your `index.html` to [netlify.com](https://netlify.com)
2. Get a shareable link instantly

### Option 3: Vercel
1. Connect your GitHub repo to [vercel.com](https://vercel.com)
2. Auto-deploys on every push

## 🎨 Customize It

You can easily personalize the invite:

- **Change the title** - Replace "Hey Kanak, Coffee peeloge mere sath?" with your message
- **Change friend's name** - Search for "Kanak" or "Dora" in the code
- **Change colors** - Modify the hex color codes (e.g., `#c2185b` is the pink color)
- **Change time slots** - Edit the `timeSlots` array in the JavaScript
- **Change messages** - Edit `guiltyMessages` array for the NO button
